# ساحر موفيز 🧙‍♂️

مكان واحد منظم تدور فيه على أي فيلم أو مسلسل أو كرتون، وتعرف فين تتفرج عليه **قانوني** — من غير إعلانات ولا مواقع زبالة.

**صنعه الساحر 🧙‍♂️** — © 2026 الساحر (Ali / alisa555er2005-ux). كل الحقوق محفوظة.

## إيه اللي فيه

- بحث بالعربي والإنجليزي في كل الأفلام والمسلسلات والكرتون.
- أقسام: أفلام، مسلسلات، كرتون وأنيمي، مصري وعربي.
- صفحة لكل عمل: البوستر، التقييم، القصة بالعربي، فريق العمل، وأعمال شبهه.
- **فين تتفرج عليه في مصر**: منصات الاشتراك/الإيجار/الشراء الرسمية (بيانات JustWatch عن طريق TMDB).
- **مصادر مجانية وقانونية**: يوتيوب وأرشيف الإنترنت، وقسم "مجاني" بيتفرج جوه التطبيق على أفلام ملك عام من أرشيف الإنترنت.
- تطبيق قابل للتثبيت (PWA) بيشتغل على الموبايل والكمبيوتر، وبيفتح بسرعة من غير نت.

مفيش هنا أي سيرفرات مقرصنة أو روابط قرصنة. اللي بيتعرض مصادر قانونية بس.

## التقنية

HTML + CSS + JavaScript خالص، من غير أي build step. البيانات من [TMDB API](https://developer.themoviedb.org/). الأفلام المجانية من [Internet Archive](https://archive.org/).

```
index.html            الواجهة والتصميم
app.js                منطق التطبيق (بحث، أقسام، تفاصيل، مشغل)
sw.js                 service worker (تثبيت التطبيق + سرعة + أوفلاين)
manifest.webmanifest  بيانات التطبيق والأيقونات
icon.svg              الأيقونة
```

## حقوق وتراخيص

- بيانات وصور الأفلام من TMDB. هذا المنتج يستخدم واجهة TMDB لكنه **غير معتمد أو مصدّق من TMDB**.
- بيانات توفر المنصات من JustWatch عن طريق TMDB.
